# CRM

---

## Описание

Можно создавать страницы из набора компонентов. Каждый компонент состоит из набора схем, схемы из набора полей.

## Стек

- python>=3.14
- FastAPI
- Pydantic
- that-depends

## Структура

    ├── application - Бизнес логика
    ├── controllers - Эндпоинты и схемы
    ├── core - Настройки и регистрация
    ├── domain - Доменые сущности
    ├── infrastructure - Инфраструктура
    │         ├── components - Компоненты
    │         ├── generators - Генераторы схем
    │         ├── resources - Хранилище (БД)
    │         └── schemas - Схемы компонентов
    └── tests - тесты
        ├── e2e - E2E тесты
        ├── integration - интеграционные тесты
        └── unit - юнит тесты


## Запуск

`uv run main.py` - запуск сервера

`pytest -svv` - запуск тестов

`pytest --cov=. tests` - процент покрытия тестами

`pytest --cov=. --cov-report=html tests` - генерация html шаблона с покрытием тестов

При переходе по ссылке http://localhost:8000/coverage будет показан модули покрытые тестами и общий процент.
